# Exercise 0: Environment and libraries
In programming, the environment is the setup in which your code runs — it includes the operating system, hardware, interpreter or runtime (like Python), system settings, and installed tools that affect how the program executes. Libraries, on the other hand, are collections of pre-written code that you import into your program to perform common tasks (such as math operations, file handling, web requests, or data analysis) instead of writing everything from scratch. In simple terms, the environment is the “workplace” your program lives in, while libraries are the “toolkits” you use inside that workplace to build functionality more efficiently.
